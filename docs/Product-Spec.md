# Cat Guardian - Product Specification

## Overview
Cat Guardian is a lightweight, AI-powered digital safety passport for cats designed for cat owners and rescue situations.

## Key Features
1. **Cat Profile**: Comprehensive identity, medical background, microchip number, visual features.
2. **Health Passport**: Vaccination records, allergies, weight history, medication schedule.
3. **Identification**: Visual traits, unique markings description, coat patterns.
4. **QR Code**: Quick shareable QR code linked to public safety card / lost mode page.
5. **Lost Mode**: One-tap toggle to flag cat as missing, showing contact info and emergency actions.
6. **AI Cat Profile**: AI-assisted cat characteristic & safety profile generator.
