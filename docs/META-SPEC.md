PROJECT: Cat Guardian
MISSION: Create a lightweight AI-powered safety passport for cats.
PRIMARY USER: Cat owners.
CORE PROBLEM: Owners need a simple way to maintain their cat's identity, health, and safety information and quickly share it if the cat goes missing.
CORE FEATURES: 1. Cat Profile 2. Health Passport 3. Identification 4. QR Code 5. Lost Mode 6. AI Cat Profile.
SEED DATA: The system must be initialized with 7 specific cats: Kiara, Golia, Meias (Socks), Vaquinha, Tigrinha, Peluda, and Gamora.
AI PRINCIPLES: AI assists but does not diagnose. Generates descriptive, not biometric, identification.
ARCHITECTURE: React + Vite + TypeScript + Supabase + Gemini API.
QUALITY: No task is complete without passing validation (Jidoka Gate).
