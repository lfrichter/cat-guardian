# Cat Guardian 🐾

> Digital Safety Passport for Cats — Hackathon DEV Weekend MVP

Cat Guardian is an AI-powered lightweight safety passport and missing cat alert system for feline owners.

## Tech Stack
- **Frontend**: React + Vite + TypeScript
- **Styling**: Modern CSS / Glassmorphism
- **Backend / Database**: Supabase
- **AI Integration**: Gemini API

## Core Features
1. **Cat Profiles**: Complete identity, microchip, photos, & behavioral notes.
2. **Health Passport**: Vaccinations, allergies, medical history.
3. **Identification**: AI-assisted physical feature descriptions.
4. **QR Code Sharing**: Instant access QR code for collar tags.
5. **Lost Mode**: Emergency broadcast & public safety card.
6. **AI Cat Profile**: Smart assistant for cat profile generation.

## Framework IA 2.0
Operates under the governance loop: `Gemini decides → Worker executes → Jidoka verifies → Human authorizes`.
